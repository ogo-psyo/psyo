## Как закрывается строка

Для каждого перехода: скрин/запись на точной RC-сборке, реальный API (либо доказанный N/A), entityId/requestId в обезличенном QA-артефакте, проверка результата после перечитывания, отсутствие старой формы и возврат в правильный источник. Дизайнерская приёмка PNG и backend-тест — разные графы. Отсутствие входа в PNG не означает, что функция удалена.

**Пока ни одна строка не принята как production-реализация нового дизайна.** Готова только спецификация; существующие QA-артефакты служат исходным материалом.
