# Карта: задачи до интерфейса

7 сентября 2026. Коррекция после обратной связи 16341–16345.
Статус: требования к переработке, не реализация и не пользовательское одобрение решения.

Этот документ уточняет SPEC.md: обязательная последовательность «категория → список → карточка → подборка» не является целевым сценарием. Категории, вкладки и кнопки — средства, а не единицы приёмки. Все существующие возможности сохраняются. Яндекс отложен. Собственная региональная база — вариант реализации источника, не требование пользователя и не обязательный вопрос к нему.

## Подтверждённые разрывы текущей ветки

- В MapLibraryPanel выбор collectionId локален: список фильтруется по подборке, но ProductionMapWorkspace передаёт карте все library.places. Обзор выбранной подборки на карте не реализован этим переключением.
- Создание и переименование подборки расположены перед списком мест. У каждой строки одновременно показаны управление заметкой, порядком, членством и выбор для прогулки. Выбор места конкурирует с управлением библиотекой.
- Передача подборки в план разрешена только при routeFlow === idle. При существующем плане предлагается сначала сохранить или удалить его: добавление найденных мест в текущую прогулку не является непрерывной цепочкой.
- В показе карточки на 390×844 сохранение оказывается ниже первого экрана. Это наблюдение по снимку, не утверждение о недоступности действия вообще.
- Проверки подтверждают операции и сохранность на фикстурах, но не удобство решения задач и не готовую реальную геовыдачу.

## Задачи и конечные результаты

| Задача человека | Короткий основной путь | Результат, который принимаем |
|---|---|---|
| Решить, куда пойти с собакой | Обозреть места в выбранной области или своей подборке → посмотреть релевантные сведения → выбрать место | Есть выбранное место, понятное положение и следующий шаг: включить в прогулку либо сохранить; неизвестные условия не выданы за разрешение |
| Собрать прогулку через несколько мест | Добавлять точки на карте, из поиска или подборки → при необходимости изменить порядок → получить актуальный путь → сохранить | Один сохранённый план с теми же остановками, геометрией и оценкой времени; открывается позже |
| Воспользоваться сохранённым | Открыть подборку или прежний маршрут → увидеть его на карте → выбрать места для текущего плана либо повторно использовать маршрут | Не нужно искать заново; исходная подборка и маршрут не изменены неявно |
| Выйти и записать прогулку | Начать запись → видеть статус при использовании карты → завершить → сохранить | Одна запись с фактическими данными и честными пропусками GPS, доступная в истории |
| Предупредить об опасности | Указать место → описать предупреждение и выбрать предусмотренную видимость → сохранить | Объект относится к выбранной точке, результат и права соответствуют действию |

«Маршрут на карте» не означает пошаговую навигацию или фоновую запись: такие обещания без реализации не добавляются. Подборки здесь пользовательские; авторские рекомендации не подменяются вымышленным наполнением.

## Единое состояние вместо цепочки меню

- Контекст просмотра: область + источник набора мест (выдача/поиск/конкретная подборка) + выбранный объект. Список и маркеры — два представления этого набора; другие включённые слои различимы и не исчезают молча.
- Выбор в списке выделяет тот же объект на карте и наоборот. Открытие подборки даёт её географический обзор, а возврат восстанавливает предыдущие камеру и список.
- Выбранное место не требует создания подборки. Быстрое сохранение показывает, куда сохранено, и позволяет отменить или изменить принадлежность; продвинутые операции доступны отдельно от основного пути.
- План — один черновик независимо от способа добавления остановки. Конструктор — представление того же плана, а не новое начало. Добавление из подборки не требует удалить текущий план. При активной записи либо несовместимом состоянии объясняется ограничение без потери работы.
- Приватные данные и выбранная собака принадлежат существующим моделям. Сокращение переходов не убирает согласие, проверку точности, ошибки или контроль видимости.

## DoR следующего связанного прототипа

- [ ] На одном наборе данных подготовлены: несколько мест, две подборки с общим местом, непустой черновик, сохранённый маршрут и запись с пропуском GPS.
- [ ] Для каждой задачи определены вход, результат, источник истины, возврат, ошибка и повтор. Зафиксированы текущие ограничения, а не придуманы новые функции.
- [ ] Разделены просмотр/выбор и необязательное управление библиотекой; ни категория, ни создание подборки не являются обязательным шагом.
- [ ] Для прототипа фикстуры помечены явно. Для реализации реальной выдачи отдельно проверен источник: фикстуры не закрывают эту зависимость. Независимые цепочки сохранённого/плана/записи не блокируются выбором источника выдачи.

## DoD сценариев, а не кнопок

- [ ] Открыть подборку A: список и карта соответствуют A; выбрать общее место, перейти к B, вернуться — нет смешения наборов и потерянного контекста.
- [ ] Сохранить выбранное место без создания/выбора новой подборки: подтверждён один результат, видна принадлежность, работает отмена. Ошибка сохраняет выбор и допускает повтор.
- [ ] Добавить место на карте, затем ещё два из подборки в тот же непустой план; изменить порядок в конструкторе; вернуться на карту и добавить точку. Все остановки, имена и порядок сохранены.
- [ ] Рассчитать и сохранить план; открыть после перезагрузки. Проверить устаревший расчёт, отсутствие пути и ошибку сохранения отдельно от успешного прохода.
- [ ] Открыть прежний маршрут для следующей прогулки без повторного поиска и без неявной перезаписи оригинала.
- [ ] Во время записи открыть место/подборку и вернуться: статус доступен, запись не перезапущена; завершение и повтор сохранения не создают дубль. Физический Telegram/GPS остаётся отдельной обязательной проверкой соответствующих обещаний.
- [ ] На 320×740 и 390×844 основные действия выбранного места доступны без прокрутки через управление библиотекой. Нет цепочки вложенных панелей; подробности могут раскрываться по запросу. Клавиатура, фокус, точность и права сохранены.
- [ ] Дать человеку задания «собери прогулку через эти места» и «найди сохранённое для следующего выхода» без подсказок, какую кнопку нажать. Зафиксировать лишние возвраты, непонятные состояния и результат. Самопроверка автора не считается независимой проверкой удобства.

Показ следующего варианта: непрерывный проход «подборка на карте → несколько мест в уже начатую прогулку → сохранение → повторное открытие», плюс самостоятельная запись прогулки. Не очередная галерея изолированных карточек. Код до проверки этих связей не объявляется готовым; этот документ не закрывает DoD.
