# Связанный UX-прототип Карты

7 сентября 2026. Локальный вариант для показа, не production-релиз и не независимая пользовательская приёмка.

## Что изменено

- Выбор подборки общий для списка и маркеров; явный выбор даёт географический обзор её мест. Предупреждения и маршруты остаются отдельными слоями.
- Места добавляются в существующий план, а не заменяют его. Повторное добавление того же сохранённого placeId не создаёт дубль; ручной возврат к началу остаётся доступен.
- После добавления пользователь остаётся в выборе мест; видны число остановок и их номера на карте. Конструктор изменяет тот же черновик.
- Управление местами/подборками и слои раскрываются по запросу. Убрано дополнительное обязательное раскрытие всего «Сохранённого».
- В карточке доступны два основных действия до выбора целевой подборки. Выбор подборки остаётся доступным; текущий вариант по умолчанию сохраняет в «Сохранённые места».
- Убран дублирующий popup маркера при наличии карточки. Уведомление сохранения карты использует её строку статуса вместо перекрывающего действия toast.
- Ручной режим сохраняет placeId при переходах. Хранение, API и права не менялись.

## Границы

Места, аккаунт, пеший расчёт и ответы сохранения в показе — фикстуры. Базовая карта загружается извне; нарисованный результат фикстуры не является проверенной реальной прогулкой. Новый источник выдачи остаётся незавершённым; выбор собственной региональной базы не является обязательным пользовательским требованием.

Шесть сценариев выше — авторская автоматизированная проверка, не доказательство того, что человек решает задачу без подсказок. Физический Telegram, фоновый GPS, реальные приватные записи аккаунта и новый UX без сопровождения здесь не приняты. Прочие задачи TASK-CONTRACT не объявлены закрытыми.

Промежуточные сбои: dev-origin при открытии 127.0.0.1 устранён использованием localhost без ослабления конфига; ошибка Leaflet во время hot reload не повторилась в финальном compiled-проходе. В проверке возврата фокуса ожидается штатный requestAnimationFrame, без принудительной фокусировки из теста. Перекрытие toast исправлено в UI и повторно проверено.
