## Ограничения

- У всех 377 объектов в исходном снимке отсутствует подтверждённый тег допуска собак. Интерфейс обязан показывать «Условия посещения с собакой: нет данных», а не pet-friendly.
- Безымянные кафе, парки, магазины и клиники исключены как неразличимые для человека. Сохранены 10 безымянных специализированных площадок для собак: для них полезна сама подтверждённая географическая точка.
- Каталог не подтверждает режим работы, телефон и актуальность правил посещения.
- Перед публичным заявлением о качестве покрытия нужны выборочная ручная проверка и регулярное обновление. Начальная рекомендуемая периодичность — раз в месяц.

## Почему этот слой нужен

Текстовый поиск Nominatim остаётся для известных названий и адресов. Региональный слой отвечает на другой вопрос: «что полезного есть в показанном районе», не выдавая личные сохранения за общий каталог и не опрашивая публичный Overpass на каждом движении карты.

## Проверка кандидата

- `npm run qa:local`: 262 теста, production-сборка и контракты прошли.
- `npx tsx scripts/qa/yaroslavl-place-ui.mts`: Chromium и WebKit прошли путь «геолокация в Ярославле → реальный `/api/map/places` → остров Даманский → неизвестные условия с собакой → сохранение в аккаунт».
- `/api/map/places` в браузерной проверке не подменяется; аккаунт и сохранение изолированы тестовыми данными.
- Production этим кандидатом не изменён.
