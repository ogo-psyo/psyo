# Псё — полный перенос дизайн-кода, 15 сентября 2026

## Действующий запрос
Руслан, сообщение16719: «Надо все приложение обновить согласно дизайн коду из макетов, чтобы все элементы были 1:1, при этом все продуктовое поведение и функционал остаются прежними с улучшенным ux».

Оригинальные HTML/CSS/шрифт/иконки из workspace/output/pso-connected-prototype — визуальная истина. Это не вдохновение и не новый дизайн. Все20представлений плюс существующие продуктовые состояния используют исходные компоненты. Нельзя вырезать функции ради совпадения только с демонстрационными экранами. Имена, факты, координаты и статусы принадлежат реальному продукту, не макетным данным.

Ранее отвергнутое глобальное меню «⋯ → Дополнительно» не реализовано. Дополнительные действия доступны в своих разделах. Они разрешены последним запросом; отдельного ожидания согласования нет.

## Сохранённые продуктовые контракты
- Профиль: canonical pet/profile/version, все паспортные, поведенческие и медицинские поля, несколько собак, загрузка/генерация/откат образа с прежними разрешениями.
- Записи: создание/редактирование/удаление/восстановление, четыре показателя, поиск/дата/история, прежний дневник и голосовое структурирование.
- Документы: существующий приватный upload/storage/list/open/download/delete. Удаление только после подтверждения. Обсуждение файла не выдаёт несуществующий разбор содержимого.
- Уход: canonical reminder, создание/редактирование/перенос/удаление/выполнение/undo, календарь/история/ICS; сохраняется atomic receipt/idempotency.
- Покупки: быстрый список плюс category/reason/planneddate; существующая атомарная связка покупки и напоминания, редактирование/удаление/возврат.
- Карта: настоящая география, библиотека мест/подборок, маршруты, GPS/pause/finish/GPX, слои/риски, ручное планирование/публичные ссылки; прежние IDs и сервисы.
- Гав: анкета/фильтры/район/сигналы, отклики/связи/контакт/блок/жалоба/закрытие/предложение места. Нельзя симулировать ответ другого владельца.
- Помощник: прежние run/thread/proposal IDs и действия, предложения следующих вопросов, продолжение диалога. Никаких фиктивных результатов провайдера.
- Настройки/публичная карточка/юридические страницы/поддержка: прежние действия, выбор видимых полей, приватность и revoke остаются.

## UX и критерии проверки
Контекст возврата, черновики, сохранение только по receipt, повтор с тем же ключом, подтверждение разрушительных действий, focus и отсутствие лишней отправки. Переключение собаки изолирует transient state. Исходная оболочка одна; старые шапки не дублируются.

Визуальная проверка и функциональная проверка независимы. Скриншоты с синтетическими API не доказывают production/live provider/физический Telegram. Дизайн-код расширений сверяется с исходными шрифтами, материалами, кнопками, формами и геометрией; API остаются прежними.
